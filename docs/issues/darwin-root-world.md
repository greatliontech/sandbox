# The darwin row refuses a stated Root until its world is delivered

Lands: docs/plans/rows.md, chunk 2.3 (the Seatbelt row's world).

The darwin row delivers its rows, probe and bounds, and the `OS`
row's profile over the caller's whole world (the network denied,
read-only grants denied their writes). A stated `Root` — the world
bounded to a tree at its host path, Apple's `system.sb` as the
execution substrate, grants and the rendezvous directory allowlisted
at their host paths, the entrypoint's load commands held to the
substrate and the tree, a sibling of the tree executed by the
entrypoint admitted — is refused as undeliverable until that world
lands, never run against a wrong one (docs/specs/sandbox.md, "Root
is world-restriction").
